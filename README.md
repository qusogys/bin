# Telegram AI Bot

Этот репозиторий — шаблон Telegram-бота с поддержкой ChatGPT (OpenAI), генерации изображений и OCR (Tesseract).

Простая инструкция:

1) В репозитории на Railway подключи переменные окружения:
   - TELEGRAM_TOKEN — токен бота
   - OPENAI_API_KEY — ключ OpenAI
   - DB_PATH — по желанию (по умолчанию data/bot.db)
   - OCR_ENABLED — true/false
   - IMAGE_PROVIDER — openai
   - IMAGE_DEFAULT_SIZE — 1024x1024

2) Деплой: Railway может использовать Dockerfile из репо. Также можно запускать локально:
   python -m app.main

Команды в боте:
- /start — старт
- /setprompt <текст> — задать системный промпт для чата
- /settings — показать настройки текущего чата
- /image <описание> — сгенерировать изображение
- Отправка фото — бот выполняет OCR и отвечает текстом

Замечания:
- Этот шаблон минимален и требует доработки безопасности, обработки ошибок и проверки лимитов.
- По умолчанию используется модель gpt-3.5-turbo для примера; можно поменять в ai_client.py.
